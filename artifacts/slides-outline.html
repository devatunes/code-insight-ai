Problema

~1 min
  • El reto: analizar un repositorio de código fuente e inferir automáticamente su funcionamiento y arquitectura — común en empresas con muchos repos sin documentación actualizada.
  • Entrada: URL Git pública (o ZIP). Salida: resumen funcional, tecnologías, arquitectura inferida (uno de 6 patrones), componentes identificados, hallazgos.
2

Arquitectura

~2 min
  • Pipeline híbrido: heurística local determinista (hechos verificables: lenguaje, framework, componentes) + Claude (interpreta y redacta, nunca inventa los hechos). Justifica el criterio de "exactitud de hallazgos".
  • Backend NestJS + Frontend Angular, patrón Strategy/Adapter para proveedores de IA (Claude funcional, OpenAI/Gemini/Ollama como stubs).
  • AWS: CloudFront+S3, ALB+ECS Fargate en VPC privada, NAT Gateway (necesario para clonar repos públicos), DynamoDB — una sola arquitectura pensada para escalar, sin versión "barata" descartable.
  • Seguridad: API key en SSM (nunca en código), Security Group del ALB restringido a IPs de CloudFront.
3

Solución implementada

~2 min
  • Funcionalidades completas: análisis end-to-end + diagrama Mermaid + historial consultable (DynamoDB).
  • Probado contra 23 repos públicos reales de lenguajes/arquitecturas distintas (Java, Python, Ruby, Go, C#, PHP, Rust, Kotlin, Elixir, Scala, React, Vue, NestJS) — varios bugs de heurística encontrados y corregidos en el camino (ej. Java no detectaba controllers por su convención PascalCase; ahora sí).
  • Límites de seguridad probados de verdad: repo de ~1.5GB (kubernetes/kubernetes) rechazado limpio por el límite de tamaño.
4

Demo

~2 min
  • Video corto: pegar URL → ver resultado (resumen, arquitectura, diagrama, componentes, hallazgos) → historial.
5

Mejoras futuras

~1 min
  • Completar carga de ZIP (hoy cascarón).
  • Desarrollar un proveedor de IA local real (Ollama) — hoy es stub; daría independencia de red/costo para repos sensibles o entornos sin salida a internet.
  • Ampliar soporte de framework/componentes a stacks que hoy no cubrimos (ej. .NET más profundo, Swift, Dart) — Go ya está cubierto (detección de framework vía go.mod y convención de nombre de archivo).
  • Observabilidad más profunda: hoy ya hay Logger de NestJS en los puntos clave + errores tipados (BadRequestException, etc.) agregados en CloudWatch Logs; falta métricas/dashboards, tracing distribuido (X-Ray) y alarmas.
  • Minería supervisada de heurística: usar el historial (heurística vs. veredicto de Claude) para sugerir reglas nuevas, siempre con revisión humana antes de aplicarlas.
